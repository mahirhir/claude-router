# Support

## Where to ask

- **Toolkit bug:** open a bug report.
- **Feature request:** open a feature request.
- **Provider/model result:** use the provider compatibility form.
- **Usage question:** use GitHub Discussions after it is enabled.
- **Security issue or leaked credential:** follow [SECURITY.md](SECURITY.md); do not open a public issue.
- **9Router/provider/OAuth problem:** use the upstream 9Router or provider support channel.

## Information to include

- toolkit version or commit;
- Windows and PowerShell versions;
- Claude Code CLI/extension version;
- 9Router version;
- provider and exact model ID;
- command or switch mode used;
- expected and actual behavior;
- sanitized output and 9Router console log.

Replace API keys, email addresses, account IDs, usernames, internal hosts, and private paths with obvious placeholders. Do not attach `config.local.json`.

## Scope

This project maintains switching, configuration validation, installation, settings preservation, and documentation. It cannot guarantee that every provider implements streaming, tools, vision, thinking, caching, or Claude protocol translation correctly.

Support is community-maintained and provided on a best-effort basis. Clear, reproducible reports with tests receive the fastest response.
